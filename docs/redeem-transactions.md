# 兑换码事务保护

兑换使用用户与兑换码行锁。锁定用户后再次检查最新账号状态：管理员先提交停用时，该请求返回 403，兑换码、余额和账本不变；兑换先提交时，已完成账本保留。

兑换码相关事务局部设置 `lock_timeout=3s`、`statement_timeout=10s`。等待超时或死锁会回滚并返回 503，提示稍后重试，不向前端暴露数据库错误。注册、订单、OAuth 等事务配置保持原状。

`npm run test:platform` 包含独立兑换测试，覆盖并发单次入账、停用竞态、锁超时后的重试、账本失败回滚、过期筛选、加密复制导出、权限和限流。使用隔离 schema，不启动注册执行器、不操作正式数据。
