# 独立 OAuth 与短信配置

本轮与用户平台、API 文档和客户订单执行流程一起整合；正式发布仍按 GitHub 拉取、预构建、空闲备份后仅重建 app / worker 的流程执行。

## OAuth 代理

- “仅注册”“注册后 OAuth”入口不变，注册后的 OAuth 继续使用该任务的 Worker 代理。
- 凭据直登使用任务面板中的国家池或固定代理；登录态资产补 OAuth 先弹出代理选择。绑定和健康检查复用注册逻辑。
- 新独立 OAuth 不再隐式使用本机 7890。注册和 OAuth 的运行实例共享代理占用表，不能同时绑定同一代理条目。
- “从检查点继续”沿用原快照；“更换代理并继续”重新登录未完成账号，保留已完成账号。有未结算短信租约或取号结果不确定时禁止更换代理。
- 旧 maintenance 任务需要显式重新选择代理。其他配置发生变化时仍保留原有指纹校验，不能强行覆盖检查点。
- 登录态刷新、安全配置恢复及 AT 测活仍保留原维护链路，不属于本轮代理改造范围。

## 短信配置

短信弹窗统一管理 SMSBower、火狐狸和 Hero-SMS。各供应商密钥独立保存；空密钥输入表示保留已存值。读取接口只返回是否配置，测试可使用尚未保存的输入，不买号。

- SMSBower 使用原 `sms` 顶层配置，火狐狸使用 `sms.firefox.token`，Hero-SMS 使用 `sms.hero`。
- Hero-SMS 默认接口为 `https://hero-sms.com/stubs/handler_api.php`，服务代码默认为 `dr`；国家目录从 Hero-SMS 查询，不复用 SMSBower 的固定目录。
- 至少勾选一个国家。先在所选、预算内且有库存的国家中随机选择，再以该国最低有效报价与配置上限中的较低值申请号码。明确缺号可尝试另一个所选国家，不扩大范围、不提高单价。
- 余额/国家/报价查询只读。只有注册、登录或 OAuth 实际进入手机验证分支才申请号码。注册后 OAuth 的启动预检不会购买号码。
- 密钥错误、网络超时、接口失败、超价和无库存分别呈现；查询失败不伪装成无库存。
- 新任务保存短信配置快照，后续切换供应商或更换密钥只影响新任务。正式 worker 的运行快照沿用现有主密钥加密。
- 未明确配置供应商接口代理时使用直连，不默认探测桌面 10808/7890；已有显式接口代理设置继续生效。

Hero 的取号与轮询采用兼容 handler 协议，完成/取消复用 Space 已有 REST 逻辑，只有 HTTP 204 确认成功。过早取消保留待清理状态。取号超时或响应不完整保留不确定结果，不自动重复购买；重启后不能可靠归属的订单需人工在供应商后台核实。

## 本地验证

覆盖供应商模拟接口、国家/价格限制、超时不重复购买、204 生命周期确认、密钥隔离、运行恢复、快照加密、未出现手机验证时不取号，以及网页配置保存和代理选择。完成后端回归、平台测试与前端构建；桌面及 390px 页面使用独立模拟服务验证。

Hero 官方文档本次访问受站点验证拦截，接口实现依据本地 Space 对接代码及其协议。本轮没有使用真实密钥购号、注册或授权；真实供应商连通性与计费结果仍需在配置后验证。
