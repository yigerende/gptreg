# 原注册管理台分页与滚动

原注册管理台采用页面纵向滚动，虚拟账号列表和日志保留独立滚动区域。隐藏竖向滚动条仅影响外观，不禁止滚轮、键盘或触摸。并行任务列表默认收起，显示任务数；展开后高度受限，可滚动切换。

## 分页范围

- 任务历史、当前任务账号队列、CPA 产物、登录态、代理本地端口和国家池手工条目、提链台账、机器人运行历史、换绑队列与结果每页 50 条。
- 后端先筛选再分页，只返回当前页及总数；查询携带 offset/limit 或登录态已有 cursor。管理员内部未带分页参数的旧调用继续兼容，注册引擎资源选择不使用界面分页。
- 页面仍能实时接收运行状态，常驻运行列表仅包含活动任务与最近 4 条摘要，不再随历史增长持续传输所有记录。
- 日志首屏 200 条，SSE 接收新事件，点击“加载更早日志”按序号加载前一批。搜索和 JSONL 下载针对已加载日志，清空仍清除整份日志。后端原有 10000 条保留上限不变。
- LinkOps 属于外部引擎，当前接口只有最近记录范围，后台对其最近最多 200 条先筛选再分页，页面明确显示该范围。更早历史需要外部服务提供分页/游标契约，不能以本项目接口假称已有无限历史。

## 批量操作

任务历史和 CPA 的全选、批次、按数量导出针对当前页，文案明确标注。登录态原有“全选匹配”继续通过独立 ID 接口跨页选择。换绑“启动全部”显式查询完整队列 ID 后执行，不会悄悄只启动当前页。任务历史 CPA 下载标志与最新任务从完整产物索引判断，不依赖当前 CPA 页。

## 验证边界

测试使用独立测试数据库和合成数据，不执行真实注册或供应商付费操作。外部 LinkOps 服务未参与实测；最近记录分页通过本地接口注入验证。此文档不代表已经发布正式环境。
