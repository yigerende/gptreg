# 运行参数与资源重试

原注册管理台最后一个菜单为 **平台配置**（`/admin/engine/platform-config`），仅管理员可访问。

页面分两次独立保存，避免更新运行参数时覆盖运营设置：

- 用户订单与并发：共用运营后台设置。启动／授权最多尝试默认 2 次（含首次），未交付账号最多换邮箱默认 2 次（不含首次），每个账号总执行时限默认 20 分钟。并发默认全平台 15、单用户 15。上线时保留正式已有设置，不重置价格或并发。
- 运行参数：邮箱轮询、短信等待／重发／换号、请求超时、代理检测及分阶段重试间隔。页面显示当前生效值、默认值、范围和说明，可搜索及单项恢复默认。

新订单保存换邮箱预算；历史订单的新增预算为 0，继续原来的次数限制。每个新引擎任务保存运行参数快照，恢复使用同一份参数。旧版未完成任务没有快照时，配置接口拒绝修改，防止检查点失效。

自动换邮箱预算用于用户工作台和开放 API 的订单。原后台手动批量任务的 `mailCount` 仍表示租用邮箱数量上限，不改成成功数量，也不额外购买邮箱补齐；邮箱收码分类、同邮箱补密码重试和短信重发／换号设置在两种入口共用。

邮箱验证码一直未到达与网络超时分别处理。注册前验证码超时进入换邮箱流程；已创建账号在补密码收码失败后，同邮箱默认额外重试 1 次，耗尽后停止旧执行、处理其外部租约并隔离未交付资产，再申请新邮箱。真实网络错误仍使用独立网络重试。创建结果不明先核实原账号，不能直接重复注册。

手机号沿用引擎的租约账本：注册接码同号码默认额外重发 1 次（可设 0～3）；超时或明确拒绝后核对迟到验证码、处理旧号码，再换新号码。OAuth 不重复发送同号码。换号默认预算仍为原来的 20 次，可设 0～30。已提交验证码但结果不明时先核实是否成功，避免重复绑定和费用。

注册每轮短信等待默认 120 秒；OAuth 每号码默认 60 秒，单独配置，恢复不重置号码截止时间。短信查询间隔现在实际读取配置，默认 5 秒（此前引擎固定 8 秒，未使用配置中的 5 秒）。平台配置共 33 项运行参数及 7 项用户订单限额，接口密钥和渠道选择继续使用原有供应商配置卡片。

换邮箱不会重置总时限、预留积分或订单序号。旧任务未清理完，新任务不会启动。旧任务迟到结果被隔离，不能替代新任务或重复交付。预算／时限耗尽时只退回一次未交付积分。所有尝试和成本继续保留在运营后台。

用户订单详情和 API 的 `message` 显示当前注册、补密码收码、2FA、短信或 OAuth 阶段；新增可选响应字段 `resource_replacements`。现有下单参数、鉴权、接口地址及幂等规则保持兼容。

`attempts`、`oauth_attempts`、`recovery_attempts` 是当前资源的计数，更换邮箱后重新计算；历史各次执行及费用保留在管理端。已注册账号优先继续原账号 OAuth，达到原账号授权重试上限后，仍可在订单换邮箱预算内停止旧执行、重新注册。
