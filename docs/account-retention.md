# 我的账号：按订单领取与 72 小时保留期

2026-11-05 实现并验证；用户随后授权与全部未提交代码一并推送和正式发布。正式版本以发布记录为准。

用户 `/accounts` 默认按订单分组，一笔订单一行，点击订单号展开账号，支持整单选择、逐条选择、本页选择，以及跨订单/跨页全选。可切换按账号平铺；更改筛选会清空选择，分页和切换视图保留选择。所有选择入口合计最多 1000 条，超出明确提示。展开每页 50 条，订单每页 20 条。CPA、SUB、邮箱-密码-2fa 和 CSV 保留下载转圈与防重复提交。

每个账号从 `platform_accounts.created_at`（实际交付成功时间）起算 72 小时，返回 `download_expires_at`。同一订单各账号按各自交付时间计算，分组显示最早删除时间，展开显示每个账号的删除时间；页面显示北京时间和剩余领取时间，剩余不足 24 小时突出提示。

“删除”仅指撤销用户领取资料的权限，不物理删除数据库行。用户页面及 `/api/user/v1`、`/open/v1` 的列表、凭据和所有导出统一按 PostgreSQL 当前时间判断；到达 72 小时的瞬间不再允许领取。已保存的 ID 同样返回 404，批量导出混入任意失效 ID 则整批失败。已下载至用户电脑的文件不受影响。

运营后台的完整账号凭据、OAuth、2FA 和导出均保留；订单、账本、资产“已卖出”状态和加密主密钥不变。无需迁移或定时删除任务，worker 停止时过期限制仍有效。以后上线时，旧账号沿用原交付时间，超过 72 小时的旧账号将立即退出用户领取列表，不重新延长领取期。

私有接口 `/api/user/v1/account-orders` 返回未过期账号按订单聚合结果，`/api/user/v1/accounts/selection` 一次最多返回 1000 条选择元数据（无凭据）。两者受用户会话、租户隔离和 accounts 功能开关保护；不增加公开 API 数量。

页面以服务端时间校准倒计时，仅本地更新剩余时间；到实际过期点局部刷新账号数据，并清除失效选择、关闭过期凭据弹窗。没有固定间隔的网络轮询或整页刷新。OpenAPI 1.3.0 与 `/docs` 同步说明保留期、截止时间字段及到期错误。

验证覆盖数据库精确 72 小时边界、混合到期订单、普通用户/API Key 旧 ID 拒绝、全部导出格式、管理员保留、租户/功能隔离、整单与跨单选择、1000 上限、导出转圈和到期关闭弹窗。浏览器验证记录保存在忽略目录 `.local/accounts-retention-20261105/`；仅使用独立预览库的合成账号，不调用真实注册供应商。
